# Protocols for acquiring data and software for testing of PETSIRD data

[![pre-commit.ci status](https://results.pre-commit.ci/badge/github/ETSInitiative/PETSIRDTestData/main.svg)](https://results.pre-commit.ci/latest/github/ETSInitiative/PETSIRDTestData/main)

The purpose of this repo is to describe acquisition protocols for PET scans
that enable testing PETSIRD converters. This is **not complete**.

## Background

The [Emission Tomography Standardization Initiative (ETSI)](https://etsinitiative.org/)
is working towards establishing a standard for PET Raw Data, called PETSIRD
("PET ETSI Raw Data"). See [github.com/ETSInitiative/PETSIRD](https://github.com/ETSInitiative/PETSIRD)
for the specification of the standard.
